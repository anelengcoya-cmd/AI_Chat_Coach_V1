# AI Chat Coach 🧠

Your Personal AI Usage Analyst - Discover patterns, growth, and insights from your AI conversations.

## Features

- 📊 **AI Usage Snapshot**: Quick stats about your AI interactions
- 📅 **Activity Timeline**: Visualize your usage over time with date filtering
- 🧠 **Cognitive Profile**: Understand how you think based on question patterns
- 📚 **Themes & Insights**: Discover recurring topics and conversation themes
- 📨 **Message Analysis**: Deep dive into message patterns
- 💬 **Chat Assistant**: Query your data with natural language
- 📥 **Downloadable Reports**: Export insights as images or CSV

## Quick Start
#### Data Privacy
All processing happens locally in your browser. No data is stored or transmitted to external servers.

#### Supported Formats
- DeepSeek: JSON export with mapping structure
- ChatGPT: JSON export with messages array
- Generic: JSON files with conversation data

Python 3.8+
